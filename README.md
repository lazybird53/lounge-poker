# 라운지포커

라운지포커 정리 문서를 바탕으로 만든 비공식 4~6인 웹 카드 추리 게임입니다. 게임 이미지 대신 자체 CSS 카드와 화면을 사용합니다.

## 실행

Windows에서는 `게임시작.cmd`를 더블클릭하면 Node.js 설치 여부를 확인하고 서버를 실행한 뒤 http://localhost:3210 을 기본 브라우저로 자동으로 엽니다. 서버를 끝내려면 열린 명령 창에서 `Ctrl+C`를 누르세요.

2026-09-20 실제 배치 실행으로 서버 시작과 첫 화면 HTTP 200 응답을 확인했습니다. Windows 명령 프롬프트의 문자 인코딩 차이로 실행이 깨지지 않도록 배치 창의 자체 안내문은 영문으로 표시됩니다.

직접 실행하려면 Node.js 22 이상에서 이 폴더를 열고 `node server.mjs`를 실행한 다음 http://localhost:3210 에 접속하세요. 별도 패키지 설치가 필요 없습니다. npm이 있다면 `npm start`도 사용할 수 있습니다.

방을 만들고 코드를 친구에게 공유하세요. 혼자서는 연습 봇을 3명 이상 추가하면 시작할 수 있습니다. 같은 컴퓨터에서 여러 창으로 테스트할 때는 서로 다른 새 탭에서 주소를 직접 열어 주세요. 로그인 정보는 탭의 sessionStorage에 저장합니다.

같은 Wi-Fi의 다른 기기는 실행 중인 컴퓨터의 내부 IP와 3210 포트로 접속할 수 있습니다(예: http://192.168.0.10:3210). 운영체제 방화벽에서 해당 연결을 허용해야 할 수 있습니다. 외부 인터넷용 공개 배포는 포함하지 않았습니다.

친구와 시작하려면 다음 순서로 진행하세요.

1. 서버를 실행한 컴퓨터에서 이름을 입력하고 방을 만듭니다.
2. 명령 프롬프트의 `ipconfig`에서 현재 연결된 Wi-Fi/이더넷의 **IPv4 주소**를 확인합니다.
3. 친구에게 `http://내부IP:3210` 주소와 화면의 방 코드를 함께 보냅니다. 방 코드만으로 다른 컴퓨터의 서버에 연결되지는 않습니다. 친구 기기에서 `localhost`를 사용하면 안 됩니다.
4. 친구들이 해당 주소에서 이름과 방 코드를 입력하면 방장이 게임을 시작합니다. 총 4~6명이 필요합니다.

접속되지 않으면 서버 창이 열려 있는지, 같은 네트워크인지, Windows 방화벽의 개인 네트워크에서 Node.js가 허용되는지 확인하세요. 게스트 Wi-Fi의 기기 간 통신 차단 때문에 연결되지 않을 수도 있습니다. 방화벽 전체를 끄지는 마세요. 포트가 이미 사용 중이면 기존 게임 서버 창을 확인하거나 PowerShell에서 `$env:PORT=3212; node server.mjs`처럼 다른 포트로 실행하고 친구에게도 같은 포트의 주소를 보내세요. `게임시작.cmd`도 설정된 `PORT`를 사용합니다.

## 구현 범위

방 생성·코드 참가, 4~6인, 개인 후보·손패, 동시 행동 선택, 순차 처리, 일반 거래·1인 투표 특수 교환·전체 투표·감시·창고·오리 승리, 공개 채팅, 라운드 기록, 재경기, 단순 연습 봇. 서버가 규칙과 정보 공개 범위를 관리합니다. 투표 카드와 다른 사람의 선택은 확정 전 공개하지 않습니다.

## 확인된 동작과 웹 버전 선택

- 같은 순차 행동은 원작처럼 선택 요청이 서버에서 처리된 순서대로 한 명씩 진행합니다. 네트워크 상황에 따라 실제 클릭 시각과 완전히 같지 않을 수 있습니다. 감시는 순차 대기하지 않고, 투표를 두 명 이상 선택하면 전체 투표로 전환됩니다.
- 특수 교환과 창고는 서버가 받을 카드 선택과 내 카드 선택을 분리합니다. 선택 전 조기 제출/중복 받을 카드 변경은 거부합니다. 창고 앞면은 공개하지 않습니다.
- 현재 설치본 코드 기준으로 일반 거래 수신자는 자기 색 카드가 있으면 그 카드가 자동 제출되고, 없을 때만 직접 고릅니다. 특수 교환 상대에게는 확인·거절 단계가 없습니다.
- 현재 설치본의 생성 객체는 4인 16장, 5인 25장, 6인 37장입니다. 실제 배분 슬롯은 각각 17·26·37장입니다. 4·5인은 셔플 경계의 같은 카드 객체가 마지막 손패와 첫 창고 슬롯에 중복 참조되고, 6인은 중복이 없습니다. 색별 카드는 N-1장, 빈 카드는 N-1장, 무지개는 4·5인 1장과 6인 2장입니다.
- 투표한 카드는 손패에 남습니다.
- 자기 색 제출도 해당 색에 가산하고, 무지개는 모든 색에 각각 +1로 계산합니다.
- 투표 선출은 최대 한 명입니다. 여러 후보가 기준을 채우면 현재 설치본은 참가자 목록에서 가장 먼저 들어 있는 최고 득표자 한 명을 선출합니다.
- 턴 제한이 없고, 감시는 다음 라운드 시작 시 해제됩니다.

원작 코드 결론·영상 관찰과 웹 편의 기능을 구분합니다. 같은 버튼 처리 순서는 현재 원작 build 24783249의 제출 요청 처리 순서를 구현합니다.

## 방 이동과 대기실

상단의 **방 나가기**로 첫 화면에 돌아가 새 방을 만들거나 다른 방 코드로 참가할 수 있습니다. 닉네임은 유지됩니다. 방장이 나가면 남은 사람에게 방장을 넘깁니다. 진행 중 퇴장하면 현재 판을 중단하고 모두 대기실로 돌아갑니다. 방장은 **대기실로** 버튼으로 판을 중단하고 봇을 추가·제거하거나 새 참가자를 받아 다시 시작할 수 있습니다.

잠깐의 연결 끊김은 복귀를 기다립니다. 30초 이상 응답이 없으면 연결 확인 중으로 표시하며, 3분 동안 돌아오지 않으면 퇴장 처리합니다. 온라인 참가자의 행동 제한 시간은 없습니다. 이 방 관리 방식은 웹 버전 편의 기능이며 원작 규칙으로 주장하지 않습니다.

2026-09-22 방 관리 변경 후 자동 테스트 54/54 통과. 두 브라우저 탭으로 방 이동·방장 승계·대기실 복귀·봇 제거/추가·일시 연결 장애 복구를 확인했습니다. 확인 창의 승인/취소는 브라우저 테스트에서 대체했고, 3분 만료는 실제 대기가 아닌 시계 입력을 이용한 엔진 테스트로 검증했습니다.

방은 메모리 저장이며 서버 재시작 시 사라집니다. 새로고침은 기존 탭에서 복구할 수 있습니다. 퇴장 후 기존 판을 이어가는 참가자 교체는 지원하지 않으며 대기실에서 새 판을 시작합니다. 공개 서비스 운영에 필요한 계정·영구 저장·음성 채팅·신고/차단·체계적인 부하 제한은 후속 개발 범위입니다. 연습 봇은 역할 비밀을 이용한 승리 판단 없이 단순 행동을 수행합니다.
