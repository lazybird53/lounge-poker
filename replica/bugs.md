# 통신 개선 버그 기록

## BUG-002: 모바일 게임 갱신 시 채팅 input 재생성
- Severity: S3
- 재현: 채팅 입력 중 봇 선택 또는 새 메시지로 상태 갱신.
- 예상: 입력창/커서 유지, 게임 화면 갱신.
- 실제: input DOM 교체. 이전 회피 방식은 한글 조합 중 게임 화면 갱신까지 지연.
- 수정: 채팅 DOM 유지, 게임 영역과 대화 목록만 갱신.
- 검증: check-mobile-experience.js의 DOM 동일성/포커스/선택 영역 및 composition 중 새 메시지 검사 통과.
- 상태: 로컬 수정, 커밋 전.

## BUG-003: 키보드 높이에서 입력창과 하단 바 겹침
- Severity: S2
- 재현: 390×844에서 VisualViewport 높이를 440으로 주입.
- 실제: 입력 bottom 365, 하단 bar top 337로 겹침.
- 수정: 가용 viewport와 실측 dock 높이 기준 배치, 채팅 목록 높이 제한.
- 검증: 가용 높이 440/320에서 전송 영역 노출 검사 통과. 태블릿 768×1024의 화면 밖 채팅도 오버레이로 수정.
- 상태: 로컬 수정, 실기기 소프트키보드 검사 대기.

## BUG-001: 방 퇴장 후 음성 leave 요청 401
- Severity: S3
- 재현: 음성 참가 후 방 나가기.
- 예상: 마이크 종료와 방 퇴장이 오류 없이 완료.
- 실제: 방에서 제거된 뒤 음성 leave 전송으로 401 발생.
- 근거: 첫 6탭 테스트의 console-2026-10-15T14-03-56-176Z.log.
- 수정: 방 퇴장 전 로컬 음성 종료, 별도 leave 요청 생략. 다음 peer poll에서 방 참가자 목록으로 정리.
- 상태: 로컬 수정, 커밋 전.
