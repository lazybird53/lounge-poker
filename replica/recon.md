# 통신 기능 개선 범위 — 2026-10-15

사용자 요청: 기존 라운지포커에 음성대화와 텍스트 채팅. 원작 동작 확정이나 전체 재구현 요청으로 확대하지 않는다.
기존 app.js/engine.mjs에 공개 채팅이 이미 있음. 기능 중복 대신 실패 복구와 표시 개선.

S01: 기존 대기실/게임의 채팅 패널 — 빈 대화, 수신, 입력, 전송 실패.
S02: 같은 방의 음성 패널 — 미참가, 권한 대기/거절, 참가, 음소거, 연결 실패, 퇴장.
F01: 방 입장 → 채팅 입력 → 전송 → 같은 방 전원 수신. 실패 시 초안 보존.
F02: 음성 참가 버튼 → 마이크 허용 → 방 참가자와 연결 → 음소거/해제 → 음성 퇴장.
F03: 게임 중에도 F01/F02 유지. 방 퇴장·세션 만료·페이지 이탈 시 마이크 종료.

원작 음성 UI와의 일치 여부는 이번에 조사하지 않았으며 웹 편의 기능으로 취급한다.
음성 데이터는 녹음/서버 저장하지 않는다. 채팅은 기존처럼 메모리 최근 60개, 재접속 시 방 수명 내 공유.
외부망 TURN, 실기기 음질, Safari/모바일 브라우저 마이크 동작은 미확인.

근거: 기존 저장소 코드 및 사용자 요구. WebRTC 공개 API:
