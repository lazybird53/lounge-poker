# 통신 보안 체크

- [x] 기존 방 토큰 인증을 모든 음성 API에 적용. 타 방 토큰/교차 Origin 요청 거부 테스트.
- [x] 음성 세션 및 수신 대상 검증, 신호 크기 제한, 초당 80개 신호 제한, 큐 상한 128개.
- [x] 채팅 문자열/240자 제한, 500ms 전송 간격, HTML escape.
- [x] 마이크는 명시적 참가 클릭 후 요청. 퇴장/페이지 이탈 시 트랙 종료.
- [x] 런타임 npm 의존성 추가 없음. 게임 상태/손패를 음성 API에 반환하지 않음.
- [ ] 외부 HTTPS 및 TURN 배포·실측. 계정/유료 서비스는 생성하지 않음.
- [ ] Safari/실제 휴대폰 권한·오디오 재생 검증.

음성 브라우저 연결에 Google STUN 기본 사용. 설정된 TURN을 쓰면 해당 운영자가 음성 중계 트래픽을 처리함. WebRTC 주소 교환에 대한 UI 안내 포함. 녹음하지 않음.
