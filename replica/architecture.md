# 통신 설계

기존 Node HTTP 인증/방 구조와 폴링을 재사용한다. 게임 규칙과 상태 전이는 변경하지 않는다.
텍스트는 기존 action/chat. 게임 행동 요청의 busy 잠금과 분리하여 게임 처리 중 메시지를 잃지 않는다.
음성은 브라우저 WebRTC 최대 6인 mesh. 서버는 방/인증/상대 음성 세션을 검사하고 offer/answer/ICE만 전달한다.
세션별 메시지 번호/ACK, 최대 128개 큐, 15초 heartbeat 만료. 방 객체별 WeakMap으로 방 제거 시 해제.
음성 DOM은 게임 전체 렌더링 밖에 유지하여 게임 갱신으로 오디오 재생이 끊기지 않게 한다.
추가 npm 런타임 의존성 없음. 기본 Google STUN, 배포자가 VOICE_ICE_SERVERS JSON으로 TURN 설정 가능.
TURN 설정은 음성 참가 클라이언트에 전달되므로 영구 관리자 키가 아닌 제한된/단기 ICE 자격증명을 사용해야 한다.
